Skeletons no longer get vanilla's "Deathrest exhaustion" (-12) mood at 0% CPU integrity; the CPU overload moods replace it. The gizmo by the draft button now reads "CPU integrity" and shows the CPU's state instead of deathrest buildings. "Soft cycle" is one targeting button: pick a repair bed, a rib cage or any spot to stand on, so it is no longer greyed out when the repair bed is taken. CPU overload, soft cycle, rib cage and repair bed texts now describe only what is happening, in the skeleton's lore, without spelling out the rules or what comes next; the overload stages are now sluggish, recalibrating and vigilant.
