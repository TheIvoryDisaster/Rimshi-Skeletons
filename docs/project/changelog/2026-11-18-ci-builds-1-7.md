The CI build now compiles both game versions: 1.6 as before and 1.7 against the Krafs.Rimworld.Ref 1.7 reference package (.NET 10). Release zips, and so the Steam upload pipeline, carry 1.6/Assemblies and 1.7/Assemblies and list 1.7 in About.xml and LoadFolders.xml. The build fails if either DLL is missing. The 1.7 package is still tagged unstable on NuGet, so bump its version in the csproj when the game updates.
