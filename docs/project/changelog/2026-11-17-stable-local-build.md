Local build fix: a plain build (Visual Studio or dotnet build) always lists both game versions (net472 and net10.0) instead of choosing them from the game files and snapshots it finds, and skips a version it has no game DLLs for at build time. Visual Studio caches the project's first evaluation and NuGet restore, so when the list changed under it the build failed with "The target ResolveProjectReferences does not exist" and "The targeting pack Microsoft.NETCore.App is not installed". build.ps1, -p:RimWorldVersion and the CI build are unchanged.
