Local build detects the installed game version: a plain build (Visual Studio or `dotnet build`) no longer assumes 1.6. It builds whichever version Steam has installed (Waylith.dll in the game folder means 1.7), saves that version's game DLLs to %LOCALAPPDATA%\Rimshi\GameRefs\<version>, and also builds the other version from its saved copy, so switching to or from the 1.7 beta no longer breaks the build. build.ps1 uses the saved copies too; -p:RimWorldVersion and the CI build are unchanged. Same fix as Tithe PR #61.
